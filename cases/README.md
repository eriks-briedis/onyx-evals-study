# Cases

Generated by `python3 scripts/make-rental-cases.py` from [questions/](../questions/). Do not edit
these files: edit the question's README.md and re-run. `npm run cases` then compiles them into
[datasets/](../datasets/), the shape promptfoo reads.

| file | what |
|---|---|
| [vic-rentals.yaml](vic-rentals.yaml) | main set, one case per question and date (16) |
| [vic-rentals-undated.yaml](vic-rentals-undated.yaml) | main set: the cases whose law is still the law on 4 Nov 2026, asked without a date (6) |
| [vic-rentals-heldout.yaml](vic-rentals-heldout.yaml) | held-out set, dated (4) |
| [vic-rentals-heldout-undated.yaml](vic-rentals-heldout-undated.yaml) | held-out set, undated (6) |

## Fields

| field | meaning |
|---|---|
| `id` | `vr-<question>-<date>`; `vr-ho-` for the held-out set; `-undated` when the question states no date |
| `category` | the question's role (date-sensitive, needs more facts, law is silent, ...) |
| `question` | what is sent to Onyx. Dated cases open with the date ("It is 1 October 2025.") |
| `document_set` | the Onyx document set searched: `vic-rentals-baseline`, all 14 PDFs |
| `expected_documents` | the PDFs a correct answer rests on: the versions in force on the date |
| `expected_not_cited` | the other versions of the same instruments |
| `must_contain` | groups of strings, one of each group must appear: the version numbers (a cheap check, not part of gold pass) |
| `judge_questions` | the rubrics the judge runs ([src/rubrics.ts](../src/rubrics.ts)) |
| `ground_truth_ref` | the law passages behind the gold: document, location, and a line of text that occurs once in that document |
| `correct_answer_summary` | the "must mention" points, one per line |
| `wrong_answer_looks_like` | the "must not say" points |
| `must_cite` | the documents and versions the answer must name |
| `in_force` | every instrument's version in force on the date, so the judge can tell a right citation from a wrong one |
| `extra.question_id`, `scenario_date`, `role` | where the case comes from |
| `extra.gold_answer` | the short correct answer, for readers; the judge grades against the points, not this text |
| `extra.optional_credit` | points worth stating but not required |
| `extra.quick` | the quick subset: each question once, on its earliest date (10 of the 16 main cases) |
| `extra.heldout`, `extra.undated`, `extra.gold_date`, `extra.dated_case` | held-out and undated bookkeeping; `gold_date` is the day whose law the undated gold describes |
