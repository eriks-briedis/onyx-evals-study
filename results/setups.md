# What ran

Generated by scripts/export-answers.py. Every (setup, date step, model) the study ran; the answers are in results/answers/<setup>.jsonl. Runs are independent repeats.

## Setups

| setup | what changed |
|---|---|
| [baseline](answers/baseline.jsonl) | the main matrix: 16 cases; Onyx's date step off and on (stock), and the perfect filter (asof) on the 10 quick cases |
| [pick25](answers/pick25.jsonl) | section-picking cap raised from 10 to 25, candidate pool 2x -> 6x (stock search, quick cases) |
| [prompt2](answers/prompt2.jsonl) | stricter prompt, persona rentals-v2 (stock search, quick cases) |
| [sonnet](answers/sonnet.jsonl) | claude-sonnet-5-5 answering (stock search, quick cases) |
| [sol](answers/sol.jsonl) | gpt-5.6-sol answering (stock search, quick cases) |
| [opusarm](answers/opusarm.jsonl) | claude-opus-5-5 answering (stock search, quick cases); same family as the judge |
| [ctx](answers/ctx.jsonl) | contextual retrieval on at indexing (quick cases) |
| [labels](answers/labels.jsonl) | version and in-force labels on every chunk, no filter (stock search, quick cases) |
| [datefilter](answers/datefilter.jsonl) | the version-filter patch, date step on (quick cases) |
| [datefilter-rest](answers/datefilter-rest.jsonl) | the version-filter patch on the 6 non-quick cases (haiku) |
| [latest-dated](answers/latest-dated.jsonl) | the patch's label-free rule: per title, the latest file dated on or before the as-at date |
| [undated](answers/undated.jsonl) | the 6 undated questions, persona rentals-undated: stock search (off) vs the patch answering as at today (on) |
| [undated-j1](answers/undated-j1.jsonl) | the undated questions on qwen, one case at a time, 300 s secondary-flow timeout (one run) |
| [oracle](answers/oracle.jsonl) | the passage oracle: the gold's law passages in the message, no search (quick cases) |
| [heldout](answers/heldout.jsonl) | held-out set, dated slots (4): stock (off) vs the patch (on) |
| [heldout-undated](answers/heldout-undated.jsonl) | held-out set, undated slots (6): stock (off) vs the patch (on) |
| [heldout-oracle](answers/heldout-oracle.jsonl) | held-out set with the gold's passages in the message, no search |
| [heldout-pick25](answers/heldout-pick25.jsonl) | held-out dated slots, the patch on, section-pick cap 10 -> 25 and pool 2x -> 6x (haiku) |
| [heldout-undated-pick25](answers/heldout-undated-pick25.jsonl) | held-out undated slots, the same probe |
